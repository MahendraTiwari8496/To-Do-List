# To-Do List 📝

A simple, modern, and responsive **To-Do List web application** built with **HTML, CSS, and JavaScript**.  
This app allows users to **add, edit, delete, and mark tasks as complete**, with data saved in **localStorage** so tasks persist even after page reload.

---

## 🔹 Features

- Add tasks using input box or press **Enter** key.  
- Edit existing tasks.  
- Delete tasks permanently.  
- Mark tasks as **completed** (with line-through and ✔️ tick).  
- **Responsive design**: Works well on desktop, tablet, and mobile screens.  
- Modern gradient background and visually attractive UI.  
- Hover effects for buttons and icons for better user experience.  
- LocalStorage integration is used.

---

## 🔹 Technologies Used

- **HTML5** – Structure of the app.  
- **CSS3** – Styling, gradients, hover effects, responsive design.  
- **JavaScript** – Task CRUD operations, event handling, localStorage.  
- **Font Awesome** – Edit and delete icons.
